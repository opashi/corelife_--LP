ABOUT CORE LIFE

Core Lifeについて

TOP › Core Lifeについて

CONCEPT

身体が変わると、
毎日が変わる。

Core Lifeは、身体の不調を一時的に和らげるだけではなく、 一人ひとりの身体と丁寧に向き合い、 より良い状態を目指していく整体ブランドです。

人の身体は、生活習慣や仕事、運動習慣、 姿勢などによって一人ひとり異なります。

だからこそ、決められた施術を行うのではなく、 お身体の状態を確認したうえで、 その方に必要な施術をご提案することを大切にしています。

身体の状態を整えることを通して、 「やりたいことを思い切り楽しめる身体」を 一緒につくっていく。

それがCore Lifeの目指す整体です。

CORE LIFE あなたの身体を、
本来の状態へ。

PHILOSOPHY

Core Lifeが大切にしていること

01

一人ひとりに向き合う

身体の状態や生活習慣は人それぞれ。 丁寧なカウンセリングと身体の確認を行い、 一人ひとりに合わせた施術を大切にします。

02

本質的な改善を目指す

その場だけの変化ではなく、 なぜ身体に不調が起きているのかを考え、 より良い身体の状態を目指します。

03

未来の健康まで考える

今の身体だけではなく、 これから先も健康的な毎日を過ごしていただけるよう、 セルフケアや生活習慣についてもサポートします。

OUR APPROACH

Core Lifeの整体

01
CHECK

まずは身体の状態を確認

カウンセリングを通して現在のお悩みや 生活習慣を確認し、身体の状態を丁寧にチェックします。

02
ANALYSIS

不調の原因を考える

身体の動きや姿勢などを確認しながら、 現在の状態を整理していきます。

03
TREATMENT

一人ひとりに合わせて施術

確認した身体の状態をもとに、 その方に合わせた施術を行います。

04
SUPPORT

良い状態を維持するために

施術だけで終わらず、 日常生活でできるセルフケアなどもご提案します。

MESSAGE

「身体を整える」ことを、
「人生を楽しむ」ことにつなげる。

Core Lifeが目指しているのは、 整体を受けることそのものを目的にするのではなく、 整った身体で、その先の毎日を楽しんでいただくことです。

仕事、スポーツ、家族との時間、 趣味や新しい挑戦。

一人ひとりが自分らしい人生を楽しめるように、 身体の面からサポートしていきます。
